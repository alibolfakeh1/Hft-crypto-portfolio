**`read_symbol`'s clock.** It reads with `t_dec = cut + 400 days`, so `bars_for_run` cannot raise on a late row. I accept this because the tape reads standing as of each close itself, and the bar comparisons show it does. It means the reader's second guard does nothing here, and this path's only guard is the tape. The date guard reads the cut, so it still holds.

**`H_max`.** On every run the last exit fell within `H_max` of its signal plus the fill minutes. So no retained trade reached the span's end on data with holes, and FP-07's promise held on these runs.

**One false alarm, stated so nobody repeats it.** My first comparison flagged cuts 1 microsecond before a decision. A stop or target event carries its minute's close as its time, which is 10 s before that minute's candle can be read. That is right under C17, because a fill is known at the fill's time and these orders rest at the venue. So I compare such events only once their minute is known.

**Vacuity.** With holes in the data, S05, S06 and S09 made few or no setups, because a flagged minute restarts `ATRD`, and the seasonal profile and `SRV` need long runs. That is why the second pass exists.
